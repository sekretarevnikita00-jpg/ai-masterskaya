# AI-мастерская · Самара

Лендинг курса по нейросетям и визуальному творчеству для ребят 14–20 лет.

## Как запустить

Это статический сайт без сборки и сервера. Откройте `index.html` в браузере или загрузите содержимое репозитория в корневую папку статического хостинга.

Для Timeweb: создайте сайт, откройте файловый менеджер и загрузите все файлы из этого репозитория в папку сайта. Файл `index.html` должен лежать именно в корне.

## Состав

- `index.html` — разметка и тексты;
- `styles.css`, `motion.css`, `atelier.css`, `cursor.css` — оформление и анимации;
- `site.js`, `program.js`, `tunnel.js`, `cursor.js`, `atelier-canvas.js` — интерактив;
- `assets/` — изображения.
